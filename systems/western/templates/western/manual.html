    计算设置

    • 黄道体系：Sidereal（恒星黄道）或 Tropical（回归黄道），两者都完整支持。行星、宫头、小行星、恒星、特殊点、Lot 都按所选的黄道体系计算。选 Tropical 时岁差不参与计算，岁差下拉框会变灰。
    • 岁差体系：只在恒星黄道下使用。
    • 计算设置（黄道体系、岁差、宫位制、月交点）一改就自动保存，下次打开沿用上一次的设置。
    • 宫位制：Whole Sign 为整宫制；其余为非整宫制。不论哪种宫位制，上升、中天、下降、天底四轴都会直接由 Swiss Ephemeris 算出（页面暂不单独显示，Lot 公式里可以用 Asc MC Desc IC 引用）。
    • 月交点：Mean Node 平交点 / True Node 真交点。
    • 星体配置：「行星」「小行星」「恒星」「Lot」「特殊点」各占一行，右边显示勾选了几个；点开在浮窗里修改。改动立即写回 settings.json，当前的盘已经排过时会自动按新设置重算。浮窗底部的「恢复默认」把这一类恢复成默认列表。
    • 星历：始终使用 Swiss Ephemeris 星历文件（common/astro/ephe 里的 .se1 文件和 sefstars.txt），不使用近似算法。缺少某个文件时，相应的点会在结果表下面列出缺哪个文件，其它点照常显示。

    星体配置

    行星

    太阳、月亮、水星到冥王星，以及罗睺（北交点）、计都（南交点），勾选哪些就计算、显示哪些。

    小行星

    • 默认提供婚神星（3）、智神星（2）、谷神星（1）、灶神星（4）、凯龙星（2060）、爱神星（433），可以删除，也可以输入 MPC 编号添加任何小行星。
    • 谷神、智神、婚神、灶神、凯龙、人龙（5145）在主小行星文件 seas_*.se1 里。其它小行星各有一个单独的文件，放在 common/astro/ephe/astN/ 里，N = 编号 ÷ 1000 取整，例如 433 → ast0/se00433s.se1，10199 → ast10/se10199s.se1。文件可以从 Astrodienst 的 Swiss Ephemeris 下载页取得。
    • 爱神星默认不勾选，因为它的文件不在默认的星历目录里；放好文件后勾选即可。

    恒星

    • 默认提供 15 颗 Behenian 恒星：大陵五、昴宿六、毕宿五、五车二、天狼星、南河三、轩辕十四、轸宿四、角宿一、大角星、贯索四、心宿二、织女一、垒壁阵四、北落师门。
    • 添加时输入 sefstars.txt 里的名称（如 Regulus）或命名（如 ,alLeo）。找不到会直接提示。

    Lot

    • 每个 Lot 有名称、代码、日间公式和夜间公式。夜间公式不填，表示这个 Lot 不分日夜。默认提供福点（Fortune）和精神点（Spirit）。
    • 公式写法：几项相加减，结果对 360° 取余。可以引用行星代码（Su Mo …）、四轴（Asc MC Desc IC）、宫头（H1…H12）、特殊点代码、小行星 #编号、恒星 *{名称}、其它 Lot @代码，以及常数度数。公式里用到的点即使没有勾选，也会单独算出来。
    • 日夜规则：每个 Lot 单独设置。「按出生日夜自动选择」时，出生时太阳的几何高度在地平线以上用日间公式，否则用夜间公式；也可以固定为日间或夜间公式。没有夜间公式的 Lot 不分日夜。
    • 改某个 Lot 的代码时，其它公式里的 @旧代码 会自动改成新代码。
    • 保存时会检查公式写法、引用的 Lot 是否存在、Lot 之间有没有循环引用。

    映点与反映点

    • 映点：以巨蟹 0° / 摩羯 0° 为轴的镜像点（黄经 = 180° − 原黄经）。反映点：以白羊 0° / 天秤 0° 为轴的镜像点（黄经 = 360° − 原黄经）。
    • 只有在「行星」里启用的主行星（太阳到冥王星）才有映点和反映点；每一个都可以单独勾选、改符号、改颜色。
    • 结果在「映点与反映点」标签页；它们与行星的相位在「相位 → 特殊点 · 恒星 · Lot · 映点与反映点」里，映点和反映点共用同一组相位类型和容许度。

    配色

    • 每颗行星、每个小行星、恒星、特殊点、Lot、映点 / 反映点，以及 12 个星座（「星座配色」），都可以在各自的设置里点色块改颜色。星盘上逆行标志 R 的颜色在「行星」里设置。
    • 颜色用在星盘、相位矩阵和相位表格里的符号上。默认配色按深色背景设计：星座按四元素（火象红橙、土象绿褐、风象黄、水象蓝紫），行星按传统对应（太阳金、月亮银、金星玫瑰、火星红、木星蓝、土星褐灰等）。

    特殊点

    • 平均 / 真实（密切）/ 插值 远月点和近月点。平均远月点即黑月莉莉丝；平均、真实近月点分别是对应远月点的对冲点。
    • 朔望点：出生前最近一次新月或满月时月亮的位置（结果里同时给出是新月还是满月、发生时刻）。满月时取月亮的位置。
    • 宿命点（Vertex）、反宿命点、东方点（East Point）。

    相位

    设置怎么生效

    • 「星体配置」和「相位」的每一项都在浮窗里修改。浮窗里的改动只是草稿：点「完成」才保存并重新计算一次；点「取消」、×、按 Esc 或点浮窗外面，放弃这次的改动（有改动时会先确认）。
    • 保存时如果有错误（例如 Lot 公式写错），浮窗不会关闭，改好后再点「完成」。
    • 列表上方有「全选」「全不选」；小行星、恒星、Lot 还有「清空」（会先确认）。「恢复默认」把这一项恢复成默认设置，同样要点「完成」才生效。

    行星选用

    • 主相位表的点 = 在「星体配置」里启用的行星和小行星，再加四轴（上升、中天、下降、天底）。12 宫头不参与相位。
    • 在「星体配置」里新启用的点默认参与相位，不想要时在这里取消勾选。默认只选主行星、罗睺计都、上升和中天。
    • 四轴（宫头）之间的相位一律不计算。罗睺–计都永远对冲，默认也跳过（可以关掉）。

    容许度

    • 主行星、每颗小行星各自单独设置；罗睺计都、四轴、特殊点、恒星、Lot、映点各一个设置。
    • 两个点之间的容许度按合成规则得出：古典半径法（默认，两者各取一半相加）、取较大值、取较小值。
    • 勾选「只用本组」的组（默认是恒星和映点）与行星之间直接用本组的容许度，不参与合成。
    • 容许度不随相位类型变化，入相、出相相同。

    相位类型

    • 默认五大相位：合相 0°、六分 60°、四分 90°、三分 120°、对冲 180°。不能删除，取消勾选即停用。可以新增相位（名称、0–180° 的角度、符号或文字），新增的可以删除。
    • 每种相位在主相位表、特殊点、恒星、Lot、映点这五处分别勾选是否计算。默认恒星和映点只算合相和对冲。
    • 同一对点同时落在两种相位的容许范围内时，两种都会显示。
    • 「计算跨星座的相位」默认开启；关闭后只认星座之间也构成该相位的情况（只对 30° 整数倍的相位起作用）。

    相位标签页

    • 主相位表：下三角矩阵，顺序是 行星 → 小行星 → 四轴。对角线上是各点的符号，最左边一列从第二行起是本行的点。每个格子第一行是相位符号，第二行是离精确相位的偏差，后缀 A 为入相、S 为出相，两种颜色区分；不标 A / S 表示精确或两点相对静止。
    • 特殊点 · 恒星 · Lot · 映点与反映点：每组一张表格，一行一个相位，只算每组的点与主相位表里勾选的行星（含罗睺计都）之间的相位。没有任何相位的组整组不显示。
    • 映点：以巨蟹 0° / 摩羯 0° 为轴的镜像点（黄经 = 180° − 原黄经），只对主行星计算。A 的映点与 B 构成相位时，B 的映点与 A 也一定构成同样的相位，表里只列一次。恒星黄道下同样以所用黄道的巨蟹 / 摩羯 0° 为轴。
    • 入相 / 出相按两点此刻的速度判断。上升、中天和 Lot 一天转一整圈，它们参与的相位基本由它们自己的运动决定；朔望点、恒星几乎不动。
    • 点的符号：行星用标准符号；小行星、恒星、Lot 的符号在「星体配置」里可以修改。

    古典设置

    入口：「计算设置 → 古典」，共四项。改动只是草稿，点「完成」才保存并重算。计算在 systems/western/astro/dignities.py。

    先天尊贵

    • 分值：入庙、擢升、三分、界、面加分；失势、入弱减分；没有入庙、擢升、三分、界、面中的任何一项时算「外来」。默认按 William Lilly：+5、+4、+3、+2、+1、−5、−4、−5。一颗行星同时有几项就加几项。
    • 三分主星体系：
      • 多罗修斯（默认）：日、夜、共管三位。火象 日 / 木 / 土，土象 金 / 月 / 火，风象 土 / 水 / 木，水象 金 / 火 / 月。
      • 托勒密（《四书》I.18）：火象 日（昼）/ 木（夜）；土象 金（昼）/ 月（夜）；风象 土（昼）/ 水（夜）；水象以火星为主，昼间由金星、夜间由月亮共管。
      • Lilly：沿用托勒密的前三组，水象日夜都是火星，没有共管。
    • 三分计分：只算当令的主星（默认）、日夜主星都算、或者日、夜、共管都算。
    • 界：埃及界（默认）或托勒密界（Lilly《基督教占星》采用的版本）。

    得时

    • 日生 / 夜生：用 Swiss Ephemeris 的 azalt 求出生时刻太阳中心的高度。默认看几何高度 > 0°；也可以改看计入大气折射的视高度 > 0°（日出前、日落后约 2 分钟的出生会因此算作日生）。
    • 派别：每颗行星可以设为日间派、夜间派或不参与。默认 日、木、土为日间派；月、金、火为夜间派；外行星不参与。
    • 水星可以设为：东出为日间、西入为夜间（默认）；固定日间派；固定夜间派；随盘（日生盘算日间，夜生盘算夜间）；不参与。
    • 日间派行星在日生盘、夜间派行星在夜生盘为得时。

    速度

    • 实际速度：Swiss Ephemeris calc_ut 加 FLG_SPEED 返回的黄经日速度（°/日），恒星黄道时同时加 FLG_SIDEREAL。
    • 平均速度有四种：
      • 平均黄经运动（默认）：各行星的平均运动（mean motion），自动配合所选黄道。回归黄道比恒星黄道多出每日约 0.0000382° 的岁差（月交点相反）。
      • 传统平均日行：Lilly《基督教占星》所列的数值，外行星和月交点没有传统值，用平均黄经运动。
      • 实际日行绝对值的平均：用 Swiss Ephemeris 对 1900–2100 年逐日计算速度绝对值再平均。内行星和外行星因为有逆行和留，这个值比平均黄经运动大很多。
      • 自定义：逐颗填写。
    • 比较方式：按速度大小比较（默认，逆行只看快慢）或按带正负号的速度比较（逆行一律算慢）。

    太阳光束

    • 可以自定义若干档（最多 6 档），每档一个名称和一个度数。默认三档：17′ 以内为日核，8.5° 以内为焦伤，17° 以内为光束下。名称可以改（例如把「焦伤」改成「灼伤」），也可以增删档位。
    • 判断时按度数从小到大，行星与太阳的黄经距离落在哪一档以内，就显示最先满足的那一档的名称，显示在行星表的「日照」一栏。太阳和交点不判断。

    星盘怎么读

    • 圆形星盘由 13 个同心圆定位（从外往里数）：画出来的是第 1、3、5、11、13 圈。
    • 第 1 宫宫头永远在正左边（整宫制也一样），黄道度数沿逆时针增加。
    • 最外一圈（第 2 圈）：各宫宫头的星座度数，顺着逆时针方向依次是 分、星座符号、度。两个宫头离得太近时，标签会自动挤开到刚好不挨着。
    • 第 4 圈：恒星，只画与行星构成相位的恒星，一律用 ✦ 表示；点一下恒星会弹出信息框（名称、位置、星等、相位），点 × 或点别处关闭。
    • 第 6–10 圈：盘中元素（启用的行星、小行星、特殊点、Lot），从外往里依次是 符号、度、星座符号、分、逆行标志 R，字号逐级变小。同一个元素的这几项排在同一条从圆心出发的射线上。
    • 元素挨得太近时，程序调整射线之间的角度让文字不重叠；第 5 圈内侧的短刻度标出每个元素的真实位置。元素多到一圈排不下时，会提示“排盘错误”。
    • 第 12 圈：宫位数字。宫位线从第 13 圈画到第 5 圈；第 1、4、7、10 宫的宫头线稍粗。
    • 所有文字永远水平正向显示。符号颜色在「星体配置」里设置。
    • 星盘大小：打开 systems/western/static/western.css，找到 --chart-max-width（最大宽度，默认 820px）和 --chart-vh-offset（窗口高度减去的值，默认 140px），改数字后刷新网页即可。
    • 鼠标停在任何一个元素上，会显示全称、位置、速度和它的全部相位。

    相位高亮

    • 点一个盘中元素：它自己着陶土色，与它构成相位的元素和恒星着灰绿色，其它元素变淡。
    • 再点一次或点空白处取消。重新排盘会清除选中状态。
    • 高亮用的是「相位」设置算出来的相位（主相位表和特殊点、恒星、Lot 三组，不含映点）。

    结果标签页

    • 星盘下方的标签页：行星、宫位、值日星 · 行星时、小行星、恒星、Lot、特殊点、映点与反映点、相位、档案资料。所有内容在点「排盘」时一次算完，切换标签页不会重新计算。标签页顺序在「工具 → 结果标签页顺序」里调整。
    • 统一写法：行星只写符号；黄经 = 星座符号 + 星座内度分秒（截断到整秒，与星盘一致）；黄纬、赤经、赤纬都用度分秒；只有速度用小数（°/日）。
    • 行星：黄经；三分主星（日、夜、共管，按所选体系）；界主星（按所选界）；面主星（迦勒底顺序，白羊第一面从火星开始）；记分（只算传统七曜）；速度（与平均速度相比快或慢多少，括号内是百分比）；顺 / 逆；得时；东出 / 西入（行星黄经在太阳之前 0–180° 为东出，太阳和交点不判断）；日照；黄纬、赤经、赤纬。
    • 宫位：第 N 宫，黄经、赤经、赤纬、速度。
    • 小行星、特殊点：名称、黄经、黄纬、赤经、赤纬、速度。
    • 恒星：名称、黄经、黄纬、赤经、赤纬、速度、星等、拜耳命名。
    • Lot：名称、黄经、速度、公式、日夜（本次用的是日间还是夜间公式）。
    • 映点与反映点：自定义符号、黄经、速度。
    • 某一类一个都没有勾选时，这个标签页不显示。某几个点算不出来（例如缺少星历文件）时，表格下方逐条写明原因。
    • 档案资料：见“人物档案”。
