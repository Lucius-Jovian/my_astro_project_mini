    计算设置

    • 黄道体系：Sidereal（恒星黄道）或 Tropical（回归黄道），两者都完整支持。黄道体系只决定算出来的那组行星 / 宫头黄经；之后的星盘、KP 星主、象征星、主宰星、Dasha 都只在这组黄经上计算，不区分它来自哪种黄道。选 Tropical 时岁差不参与计算，岁差下拉框会变灰。
    • 岁差体系：KP 用 Krishnamurti，传统 Parashari 常用 Lahiri。
    • 宫位制：Whole Sign 为整宫制；其余为非整宫制，见下文“星盘怎么读”。
    • 月交点：Mean Node 平交点 / True Node 真交点。
    • 主行星：勾选的才会计算，也才会出现在星盘和结果表里。罗睺 / 计都只要勾选就一定画在星盘上。
    • KP：勾选「启用 KP」时，KP 行星星主、KP 宫位星主、行星象征宫位 ABCD、宫位象征星 1234、主宰星作为一个整体一起计算，对应的标签页一起出现；不勾选时它们都不计算、标签页隐藏。Vimshottari Dasha 永远计算。
      • KP 卜卦也在这一栏里：启用 KP 后才能设置，启用卜卦后用卜卦数字推算上升点。KS-N 数字范围 1–249，CIL-N 为 1–2193。
      • 已经排过盘时，切换「启用 KP」会立即按新设置重算一次。
    • 高级：
      • Dasha 起算行星：大运从哪颗行星的星宿起算，默认月亮；可以选任何在「主行星」里已勾选的行星（包括罗睺 / 计都）。取消勾选当前起算行星时，自动退回月亮。
      • Dasha 年长度：Vimshottari Dasha 一“年”按多少天计算，默认 365.25。
      • 星历：始终使用 Swiss Ephemeris 星历文件（common/astro/ephe 里的 .se1 文件）。缺少覆盖该日期的文件时直接报错并提示缺哪个文件，不会悄悄改用精度较低的内置算法。

    星盘怎么读

    星盘右上角切换北印度 / 南印度，一改就自动记住（systems.vedic.chart_style）。

    北印度星盘

    • 最上方的菱形是上升点所在的星座，逆时针依次往下排。
    • 格内尖角处的数字是星座：1 白羊、2 金牛、3 双子、4 巨蟹、5 狮子、6 处女、7 天秤、8 天蝎、9 射手、10 摩羯、11 水瓶、12 双鱼。
    • 格内元素“中心优先”，整块对准格子的几何中心：
      • 四方形（菱形）格：3 个以内竖排；4 个排成 2×2。
      • 侧立三角形（尖朝左 / 右）：4 个以内竖排。
      • 正立 / 倒立三角形（尖朝上 / 下）：2 个以内竖排；3 个为 1+2，4 个为 1+1+2（从尖角数到底边，宽的一行贴着底边）。
      • 竖排时各元素左边缘对齐成一列，整列居中。更多元素时自动选择最匀称、最紧凑的排法。
      • 全盘统一字号，尽量大；只有特别挤的格子才单独缩小。

    南印度星盘

    • 星座位置固定：左上角双鱼，顺时针依次是白羊、金牛、双子……；上升星座的格子左上角有一道斜线；每格右上角的小数字是星座编号（与北印度盘相同，可点击）。
    • 每个格子里每行一个点，所有点左边缘对齐成一列，整列在格子里水平、垂直居中；格子高度随点数自动增高。

    格子里的内容

    • 每个格子永远只代表一个星座的 0°–30°，度数是星座内度数。
    • 行星：Su 太阳、Mo 月亮、Me 水星、Ve 金星、Ma 火星、Ju 木星、Sa 土星、Ra 罗睺、Ke 计都。
    • 代号下有红色下划线 = 逆行。罗睺、计都本来就是逆行，不标。
    • As = 上升点。整宫制时总会标出；非整宫制时 H1 就是上升点，只有两者不同（如 Equal/MC 宫制）才另标 As。
    • H1–H12（灰蓝色）= 非整宫制下各宫宫头所在的位置。整宫制不显示宫头，因为“星座 = 宫”。
    • 鼠标停在任何一个点上，会显示全称和完整位置。

    相位高亮

    • 点行星 → 看它相位哪些星座：它所在的星座着陶土色，受它相位的星座着灰绿色，星盘下方一行文字列出具体星座。
    • 点星座数字 → 看哪些行星相位这个星座：这个星座着陶土色，从其它星座向它投射相位的行星加框高亮，星盘下方列出“哪颗行星、从哪个星座、第几相位”。同一星座里的行星不算。
    • 再点一次或点空白处取消。
    • 相位按星座计（Parashari 星座相位），从所在星座数起，所在星座本身算第 1 个： Su / Mo / Me / Ve 看第 7；Ma 看第 4、7、8；Ju 看第 5、7、9；Sa 看第 3、7、10；Ra / Ke 看第 5、7、9。
    • 整宫制下“星座 = 宫”，例如木星在 1 宫，则 1、5、7、9 宫高亮；非整宫制下按星座算，例如木星在白羊，则白羊、狮子、天秤、射手高亮。
    • 切换南北印度盘时，选中状态会保留；重新排盘会清除。

    结果标签页

    • 星盘下方的标签页切换各项结果：Vimshottari 大运、行星、宫位、值日星 · 行星时、KP 行星、KP 宫位、KP 行星 ABCD、KP 宫位 1234、KP 主宰星。顺序在「工具 → 结果标签页顺序」里调整。
    • 统一写法：行星用两字母代码（Su Mo Ma …）；宫位写「第 N 宫」；黄经 = 中文星座 + 星座内度分秒；星宿写梵文名加中文宿名，其余都不重复中英文。
    • 行星：黄经、星宿、宿主星、Pada（星宿四分之一，每份 3°20′）、顺 / 逆（按速度正负）。
    • 宫位：十二宫宫头的黄经、星宿、宿主星、Pada。
    • KP 行星、KP 宫位：黄经、星宿、星座主、宿主星、子主星、子子主星、Pada。
    • 度分秒截断到整秒，不四舍五入，与星盘上的显示一致。黄经、速度等原始数值在「工具 → 原始参数」里看。
    • 星座、星宿、宿主星、Pada 是印度占星的通用基础，由 systems/vedic/astro/basics.py 直接按黄经计算（不查表）；KP 星主表也从这里取这几项，只用 sub-sub.csv 查 Sub / Sub-Sub 星主。
    • Vimshottari Dasha：排盘后只计算第一层大运（L1），底色和 ● 标出当前所在的一支。点击任意区间才计算并展开下一层（L2、L3…），再点一次收起，可以逐层往下展开。第 1、2 层只显示日期，第 3 层起显示到分钟（当地时间）。起算行星和一年的天数在计算设置里。
    • 档案资料：见“人物档案”。
