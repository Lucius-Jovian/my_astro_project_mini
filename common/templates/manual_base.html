启动与退出

  • 打开 WinPython Command Prompt，进入项目文件夹（cd /d 项目所在的文件夹），再执行 python app.py。
  • 浏览器打开 http://127.0.0.1:5300/（端口以 settings.json 的 server.port 为准）。
  • 退出：在命令行窗口按 Ctrl + C。

两个占星体系

  • 顶部左边的按钮切换「印度占星」「西方占星」。两个体系共用同一套人物档案：切换后档案库和选中的人物保持不变。
  • 两个体系的计算设置分开保存（例如印度占星默认恒星黄道，西方占星默认回归黄道），互不影响。
  • 下次打开程序时，自动进入上一次使用的体系。

数据来源

当前时间

自动填入电脑的当前时间和时区，并通过浏览器定位填入经纬度。浏览器定位由系统决定实际来源（GPS、Wi-Fi、基站或融合定位），网页拿不到具体来源，只能拿到“报告精度”。拒绝授权、系统定位关闭或 8 秒超时时，使用 settings.json 里的默认地点。

手动输入

自己填写时间、时区、经纬度，然后点右上角「排盘」。

人物档案

切换到这个模式不会弹出任何窗口；点「选择人物…」在浮窗里挑一个人，会立刻用他的出生资料排盘。之前选过人物的话，切回这个模式时会自动恢复他的出生资料并排盘。

任何模式下修改了数值，都需要再点一次「排盘」才会按新数值计算。

日期时间输入与时间步进

输入日期时间

  • 年、月、日、时、分、秒各是一个小格子，只能输入数字（年 4 位，其余 2 位）。
  • 点进一格会全选，直接敲数字就会覆盖；一格填满会自动跳到下一格；月份敲 2–9、日敲 4–9、时敲 3–9、分秒敲 6–9 时，因为不可能再有第二位，会自动补零并跳格。
  • 在空格子里按退格回到上一格；← → 在格子之间移动；↑ ↓ 加减当前这一格（只改这一格，不进位）。
  • 敲 - / . : 或空格会补齐两位并跳到下一格。
  • 可以把 1990-05-12 08:30:00 这样的整段文字粘贴进任意一格。
  • 日期不存在（如格里历 2023-02-29）或数值超出范围时，格子变红并在下面提示原因。儒略历按儒略历的闰年规则检查。
  • 在任意一格按回车 = 排盘。

时间步进

  • 日期时间下方选好步长，点 ＋ 往后（更晚）、点 − 往前（更早），每点一下立刻重新排盘。
  • 步长：1 年、半年、1 个月、1 周、1 天、12 小时、1 小时、10 分钟、4 分钟、1 分钟。年和月按日历走（1 月 31 日 + 1 个月 = 2 月 28 或 29 日），天及以下按固定时长走；时区不变。
  • 4 分钟：地球每 4 分钟左右自转约 1°，上升点和宫头平均每 4 分钟移动约 1°（实际快慢随上升星座和纬度变化），适合逐度检查上升点和宫头；行星在几分钟内几乎不动。
  • 步进时会显示“相对起点 +x 天 x 小时 x 分”，点「↺ 回到起点」回到第一次步进之前的时间。手动改过时间后，起点重新计算。
  • 人物档案模式下步进只改表单里的时间，不会自动保存到档案；只有在「编辑档案」里点保存才会写入（可以用来做出生时间校正）。

人物档案

侧栏

  • 侧栏只显示当前人物（名字、出生时间、时区、经纬度、标签）和三个按钮，不会因为档案多而变长：「选择人物…」「编辑档案」「新建档案」。

选择人物（浮窗）

  • 列表每页 50 人，每行显示名字、标签和出生时间；鼠标停在一行上能看到最后修改日期。点一行（或用 ↑ ↓ 选中后回车）即选中并排盘，浮窗自动关闭。
  • 搜索框按名字模糊搜索，输入即查；在搜索框里按 ↓ 跳到列表。
  • 「筛选」展开更多条件，按钮上的数字是正在生效的条件数：
    • 出生：可写 1980、1980-05 或 1980-05-12，只填一边也可以。写法不对时输入框会变红，并暂不查询。
    • 标签：输入后回车添加，可以加多个；加了两个以上会出现“全部满足 / 满足任一”。点标签上的 × 取消。
    • 数值：先选一个“数字”类型的自定义字段，再填最小值和 / 或最大值（含边界），只显示该字段数值在范围内的人；没填这一项的人不会出现。
    • 排序：名字、出生时间、最近修改、创建先后、纬度、经度，以及每个“数字”类型的自定义字段。
    • 「重置」清除全部筛选，恢复按名字正序。
  • 翻页：列表下方的 ‹ › 翻页；中间的页码框可以直接改，回车跳转。
  • 按 Esc、点 × 或点浮窗外面关闭。

编辑档案 / 新建档案（浮窗）

  • 出生时间、时区、经纬度取自左侧「时间与地点」（浮窗顶部会显示将要保存的值）；人物名称、分类标签、自定义字段在浮窗里填写。
  • 保存修改：覆盖当前人物的档案。另存为新档案：不改原档案，另存一份。删除：删除当前人物，不可恢复。新建时只有「创建档案」。
  • 按 Ctrl + 回车保存。
  • 分类标签用逗号分隔；下方的常用标签点一下加上，再点一下去掉。

档案资料（结果标签页）

  • 人物档案模式下选中人物后，结果区会出现「档案资料」标签页，完整显示所有已填写的自定义字段，保留换行和分段。
  • 很长的字段先显示开头几行，点「展开全文」看全部。

自定义字段

  • 增加字段后，所有档案都会多出这一项；删除字段会同时删掉所有档案里这一项的内容（连同它的全部下级字段），不可恢复。
  • 类型：文本（多行，可写长篇内容，编辑框随内容自动变高并显示字数，单个字段最多 20000 字）；数字、日期（可按大小排序、按范围筛选）；单选、多选（可按选项筛选）；分组（自己不存内容，只用来收纳下级字段）。
  • 字段嵌套：任何字段都可以有下级字段，最多 5 层。例如分组「婚姻」下面放「婚姻状况」「结婚次数」「是否二婚」「婚姻详情」，再在「婚姻」下面建分组「第一段婚姻」，里面放「结婚日期」。
    • 新建时在「上级」里选放在哪个字段下面；已有字段在自己那一行改「上级」即可移动（连同全部下级一起移动）。
    • 同一级里字段名不能重复，不同上级下面可以重名（例如两段婚姻下都有「详情」）。字段名里不能有「/」。
    • 编辑档案、档案资料里按树形缩进显示；档案资料只显示自己或下级填了内容的字段。
    • 排序、筛选下拉框里写完整路径，如「婚姻 / 结婚次数」。全文检索的命中位置同样显示路径。
    • 拖动把手只在同一级里调整先后。
  • 文本改成数字时，无法识别为数字的旧内容仍会保留，只是不参与排序；之后保存这些档案前需要先改成数字或清空。
  • 字段名改完按回车或点别处即保存。必备字段（人物名称、出生时间、时区、经纬度）不能删除。

外观与版面

  • 程序只有一套深色配色。
  • 经纬度默认用度分秒输入，可以在「时间与地点」里切换成十进制；选择自动写回 user_data/settings.json 的 appearance。
  • 星盘下方结果区标签页的顺序：在「计算设置 → 工具 → 结果标签页顺序」的浮窗里调整（拖动左边的把手，或点 ↑ ↓），点「完成」才生效；标签栏上不能直接拖，防止误触。两个体系各记一份顺序，写回 layout.tab_order。
  • 「计算设置 → 工具 → 原始参数」：以浮窗查看当前这张盘后端传回的全部原始数值（黄经、黄纬、赤经、赤纬、速度等，不四舍五入），用来核对、校正计算代码。印度占星有行星、宫位、值日星 · 行星时三类；西方占星另有小行星、恒星、特殊点、Lot、映点与反映点。「复制本页 JSON」把当前这一类复制到剪贴板。
  • 「计算设置 → 工具 → 导出设置」：把两个体系的全部计算与显示设置（计算设置默认值、星体配置、相位、古典设置、星盘样式、默认地点、外观、标签页顺序）存成一个 JSON 文件。不含服务器地址、上次使用的档案库和人物，也不含任何档案数据。
  • 「导入设置」：选择导出的 JSON 文件，其中包含的各项设置替换当前设置，导入后页面重新载入。别的项目组拿到这个文件导入，就能用完全相同的设置起盘。文件里不合法的内容会按默认值纠正。
  • 结果表的第一列统一叫「名称」。
  • 「值日星 · 行星时」只放一张表：值日星、行星时主星、日出、日落、第几个行星时、这个行星时的起止时间。
  • 左侧各个折叠栏的开 / 合状态记在浏览器里，下次打开保持原样。

人物档案数据库

  • 位置：user_data/libraries/。每个档案库是一个文件 名字.sqlite3，加密前后文件名不变。
  • 程序运行期间旁边会出现 -wal 和 -shm 两个文件（WAL 模式，读写互不阻塞），属正常现象，不要单独删除它们。
  • 为几十万份档案设计：列表、排序、按字段筛选、两字及以上的全文检索都走索引；CSV 导出边读边写，不会把整库读进内存。20 万份档案实测：翻页、排序、打开和保存一份档案都在 5 毫秒以内；按字段筛选、全文检索一般在 0.1–0.3 秒；加密库与未加密库基本相同。
  • CSV 的自定义字段列名是完整路径，如 婚姻/结婚次数；分组本身不占列。导入时遇到不认识的路径，会自动建好字段，缺少的上级建成分组。
  • 备份：先关闭程序（命令行 Ctrl + C），再复制整个 user_data 文件夹。
  • 不要把数据库放在网络共享盘上。

档案库加密

  • 加密按档案库分别设置，每个加密的档案库有自己的密码。未加密的档案库照常使用，不受影响。
  • 入口：先切换到要加密的档案库，再点左上角档案库名称打开菜单，选「当前档案库加密…」。在这里加密、立即锁定、更改密码、取消加密，都只作用于当前档案库。
  • 加密用 SQLCipher 4（AES-256，每页 HMAC-SHA512 校验，密钥由密码经 PBKDF2-HMAC-SHA512 256000 次推导）。整个文件从第一个字节起就是密文，WAL 文件同样加密。
  • 加密后照常在磁盘上按页读写，不需要把整库载入内存，几十万份档案也和未加密时一样流畅。解锁时做一次密钥推导，约 0.2–1 秒。
  • 档案库菜单里，加密的库名后面有一个锁形图标；锁定中的库不显示人数。
  • 打开程序时，如果上次用的档案库是加密的，要先输入它的密码；也可以在解锁窗口里改用其他档案库。从菜单切换到锁定的库时，同样会弹出解锁窗口。
  • 密码只在程序运行期间留在内存里，关掉程序后所有加密库重新处于锁定状态。
  • 密码不保存在任何地方，忘记密码，这个档案库无法找回。请定期备份 user_data 文件夹。
  • 用 DB Browser for SQLite（打开时选 SQLCipher 4 默认设置）输入同一个密码，也能直接打开加密库。
  • 需要 sqlcipher3-wheels 库（pip install sqlcipher3-wheels，Windows 有现成的安装包）。没装时加密不可用，其它功能照常。
  • CSV 导出的文件是明文，请自行妥善保管。

settings.json

位置：user_data/settings.json。程序启动时读取一次；手工修改后需要重启程序。

  • server：监听地址和端口（默认 5300）。
  • default_location：定位失败时使用的默认地点。
  • birth_defaults.calendar：默认历法，g 格里历 / j 儒略历。
  • session：上次用的档案库、每个库里上次选中的人、上次打开的体系。
  • appearance：coord_format（dms 度分秒 / decimal 十进制）。
  • layout.tab_order：每个体系结果区标签页的顺序。
